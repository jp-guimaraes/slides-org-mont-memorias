Registrador

O que é cache?

Estratégia de trazer antecipadamente dados de uma memória mais lenta para uma mais rápida — apostando que serão pedidos em breve

Baseada no princípio da localidade: ao acessar uma posição de memória, é provável que as posições vizinhas também sejam acessadas logo em seguida

  • Cache hit ✅ — o dado antecipado foi mesmo pedido
  • Cache miss ❌ — o dado não estava lá, precisa buscar na memória mais lenta

Memória Cache

Também dentro do chip da CPU (L1/L2/L3) — cada cache miss sobe um nível, até chegar na RAM

SRAM (Static RAM)

  • Significa: Memória RAM Estática (static)
  • Funcionamento: Cada bit é armazenado em flip-flops — não precisa de atualização constante
  • Velocidade: 🔥 Muito rápida
  • Uso comum: Cache de processadores
  • Vantagem: Acesso extremamente rápido
  • Desvantagem: Alto custo e baixa densidade

DRAM (Dynamic RAM)

  • Significa: Memória RAM Dinâmica (dynamic)
  • Funcionamento: Cada bit é armazenado em um capacitor, que precisa ser recarregado (refresh)
  • Velocidade: Média — mais lenta que a SRAM
  • Uso comum: Memória principal (RAM) de computadores
  • Vantagem: Alta capacidade e baixo custo
  • Desvantagem: Necessita atualização constante e é mais lenta

Relembrando conceito de densidade

SDRAM (Synchronous DRAM)

  • Significa: Memória RAM Dinâmica Sincronizada
  • Funcionamento: Opera sincronizada com o clock do processador
  • Velocidade: 🚀 Mais rápida que a DRAM convencional
  • Uso comum: DDR, DDR2, DDR3, DDR4, DDR5 (evoluções da SDRAM)
  • Vantagem: Melhor desempenho em sistemas modernos
  • Desvantagem: Maior consumo e complexidade

Syncronous Dynamic RAM-> SDRAM (desde 1992, geração clock) — ainda dominante hoje

  • DDR, DDR2, DDR3, DDR4, DDR5

Overclock x Underclock

Overclock: sobrecarregar a frequência de trabalho acima da especificação nominal

Underclock: reduzir a frequência de trabalho abaixo da especificação

A tríade memória–placa-mãe–processador

A frequência de trabalho da RAM não é isolada — precisa estar compatibilizada com placa-mãe e processador

Se a memória suporta frequência maior do que a dupla placa-mãe/processador sustenta, o sistema faz underclock automático de todo o conjunto

Nota prática: computador travando com frequência? Pode ser memória configurada acima do que a combinação placa-mãe/processador suporta — underclock manual costuma resolver, com perda de desempenho geralmente irrelevante

Acesso sequencial!

Cluster = unidade mínima de alocação — como uma gaveta de tamanho fixo

Exemplo: arquivo .txt só com a letra “J” (8 bits em ASCII) → ocupa um cluster inteiro (NTFS: 4 KB padrão), não os 8 bits reais

Atenção: um .docx equivalente ocupa vários KB a mais que isso — mas essa diferença extra vem do próprio formato do arquivo (contêiner ZIP/XML), não do tamanho do cluster. São dois fenômenos distintos, não confundir

Trade-off: cluster maior = menos endereçamento, mais desperdício em arquivo pequeno

Memória Flash

Características:

  • Não volátil
  • Não possuem partes móveis
  • Baixo custo (ainda maior do que HD)
  • Volume reduzido
  • Baixo consumo energético
  • Alta resistência (Durabilidade, segurança)

Desvantagens:

  • Número limitado de operações de leitura/escrita
  • Energização periódica

De onde vieram?

  • ROM (Read-Only Memory): Memória somente leitura, utilizada para armazenar dados permanentes.

  • PROM (Programmable Read-Only Memory): Memória somente leitura programável uma única vez pelo usuário.

  • EPROM (Erasable Programmable Read-Only Memory): Memória somente leitura programável e apagável por exposição à luz ultravioleta, por exemplo.

  • EEPROM (Electrically Erasable Programmable Read-Only Memory): Memória somente leitura programável e apagável eletricamente.

Memória Unificada

Uma arquitetura, uma tendência — CPU, GPU e NPU compartilhando o mesmo pool físico de memória

O que é?

Alternativa ao Dual Channel: em vez de multiplicar canais, aproxima a memória fisicamente do processador

Chips de memória dentro do mesmo encapsulamento do chip, compartilhados entre CPU, GPU (e NPU)

✅ Menor latência, sem cópia entre memórias de CPU/GPU

❌ Memória soldada — não é mais substituível/upgradável pelo usuário

Uma tendência, não só a Apple

Toda a indústria (Apple, AMD, NVIDIA) está apostando em memória unificada para acelerar IA local — a banda de memória só cresce:

Sistema (ano) Memória Banda
Desktop DDR5 Dual Channel módulos, GBs ~100 GB/s
Apple M1 (2020) até 16GB 68 GB/s
Apple M1 Ultra (2022) até 128GB 800 GB/s
AMD Ryzen AI Max+ 395 (2025) até 128GB ~256 GB/s
NVIDIA DGX Spark (2025) 128GB 273 GB/s
Apple M5 Max (2026) até 128GB 614 GB/s
Apple M5 Ultra (2026) até 512GB 1,2 TB/s

Mas atenção

Mesmo assim, memória unificada ainda perde em banda bruta para a VRAM dedicada de uma GPU discreta (1000+ GB/s)

O ganho real é eliminar a cópia de dados entre CPU e GPU — não superar uma GPU de ponta em banda

Aspectos relacionados a memória

ECC (Error-Correcting Code)

Tipo de RAM capaz de detectar e corrigir automaticamente um erro de 1 bit por palavra de memória

Usa bits extras de paridade/verificação gravados junto com o dado

Uso: servidores (24h/dia, centenas de GB de RAM) — praticamente ausente em desktops/notebooks

Bit flip

Inversão espontânea do valor de uma célula (0 vira 1, ou vice-versa) sem dano físico permanente

Duas causas (radiação ionizante):

  • Raios cósmicos secundários (nêutrons)
  • Partículas alfa de contaminantes radioativos no próprio encapsulamento do chip

Quanto menor o chip e maior a quantidade de memória, maior a probabilidade de bit flip

Quiz final

Bit flip (Seção de Memória Primária) é o mesmo problema que um HD perto de um ímã forte?

Resposta

Não — mecanismos físicos diferentes:

  • HD: perde dado por magnetização externa de uma região do prato
  • RAM (bit flip): perde dado por radiação ionizante (raios cósmicos, partículas alfa) perturbando a carga elétrica (DRAM) ou o estado lógico de um circuito (SRAM)

Duas ameaças, dois mecanismos — não confundir
